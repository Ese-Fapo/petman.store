# JUSTPETS

JUSTPETS is an Ireland-based pet shop storefront built with Next.js, Tailwind CSS, Redux Toolkit, and Lucide React.

The site is branded for pet food, toys, bowls, treats, supplements, bird care, and small-pet essentials, with Dublin contact details and euro pricing.

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.

## Features

- Customer storefront for browsing pet products
- Product detail pages with reviews and cart actions
- Store dashboard pages for managing pet shop products and orders
- Admin dashboard pages for stores, approvals, coupons, and reporting

## Tech Stack

- Next.js
- React
- Tailwind CSS
- Redux Toolkit
- Lucide React
